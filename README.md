# Anemos Aircraft

[English](README.md) · [Русский](README.ru.md)

Anemos Aircraft is a student project from Selçuk University in Konya, Turkey. We are designing a small electric drone that takes off and lands vertically and flies like an airplane in between.

This repository holds the public side of the project: the brand kit and a short description of the aircraft. Everything else stays in our working repository.

## Anemos ANY1

ANY1 is a fixed-wing VTOL drone in the 10 kg class with a wingspan of about 3 m.

It has three motors. The two on the wing tilt: they point up for take-off and landing and turn forward for cruise. The third sits on the tail boom and only helps in hover; in forward flight it stops. A V-tail on a single carbon boom takes care of pitch and yaw in cruise.

The payload bay is swappable, so the same airframe can carry a mapping camera, a thermal camera or a drop mechanism. Flight control runs on ArduPilot.

The aircraft is still being designed. Numbers will change as calculations and tests move on, so we only publish the general picture here.
