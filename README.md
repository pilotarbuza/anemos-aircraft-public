# Anemos Aircraft

Открытые материалы проекта Anemos Aircraft: фирменный стиль и общее описание беспилотника Anemos ANY1.

ANY1 — учебно-исследовательский БПЛА вертикального взлёта массой до 10 кг: тилт-трикоптер с двумя поворотными моторами на крыле, неподвижным задним мотором на хвостовой балке и V-оперением. Проект ведут студенты-механики университета Selçuk (Конья) как дипломную работу и для конкурсов IMechE UAS Challenge и TEKNOFEST.

## Использование

- Логотип не перерисовывать и не набирать шрифтом: берите готовые файлы из `01_Логотип`.
- Шрифты Unbounded, Manrope, JetBrains Mono и Doto распространяются по SIL Open Font License 1.1, тексты лицензий лежат рядом с файлами.
- Концепция описывает рабочую версию проекта; цифры в ней эскизного уровня и будут уточняться расчётами и испытаниями. Ссылки на внутренние документы (`A1_revCplus.md` и другие) ведут в закрытую часть проекта.
