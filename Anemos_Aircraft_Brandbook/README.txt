ANEMOS AIRCRAFT — ПАКЕТ ФИРМЕННОГО СТИЛЯ, версия 1.0 (октябрь 2026)

00_Брендбук   Брендбук в PDF: идея, голос, знак и построение, логотип, охранное поле,
              цвет, типографика, сетка, графика, компоненты, примеры применения.

01_Логотип    SVG — исходники: знак, логотип, горизонтальная связка, связка с AIRCRAFT,
                    вертикальная связка. Версии: color, reverse (для тёмного/бирюзового фона),
                    mono-dark, mono-white (одна краска, без огня).
              PNG — то же на прозрачном фоне: знак 512/1024/2048 px, связки 1000/2000/4000 px.
              PDF — вектор для типографии.
              Favicon — favicon.ico/.svg, 16–512 px, apple-touch-icon, иконка приложения 1024.

02_Цвета      anemos-palette.ase (Adobe), .gpl (GIMP, Inkscape, Krita), anemos-tokens.css,
              anemos-tokens.json, Цвета.txt (HEX / RGB / CMYK).

03_Шрифты     Unbounded, Manrope, JetBrains Mono, Doto + лицензии OFL.

04_Графика    Зерновые градиенты (фоны), линии тока, точечная сетка, шкала для расчётных полей.

05_Шаблоны    Визитка 90×50 мм (PDF, вылет 2 мм), аватары 1080, обложка 1500×500,
              слайды 1920×1080: титульный, разделитель, рабочий.
